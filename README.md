# Easy Vocabulary

Веб-приложение для изучения английских слов по системе уровней CEFR (A1-C2). 180 уровней, ~10 000 слов, отслеживание прогресса и мотивационные механики.

Демо: https://shashkinairina.github.io/easy-vocabulary/

## Возможности

- 6 уровней CEFR: A1, A2, B1, B2, C1, C2
- 180 уровней с постепенной разблокировкой
- Проверка ответов с мгновенной обратной связью
- Подсчёт серий правильных ответов (streaks)
- Звёзды за прохождение уровней (1-3 звезды)
- Сохранение прогресса в localStorage
- Адаптивная вёрстка для мобильных и десктопов
- Поддержка клавиатуры: Enter для проверки ответа

## Технологии

- HTML — структура страницы
- CSS — стили, адаптивность
- JavaScript — логика приложения
- Fetch API — загрузка базы слов из JSON
- localStorage — сохранение прогресса
- JSON — база слов (~10 000 записей)

Без фреймворков и внешних зависимостей — чистый ванильный JS.
